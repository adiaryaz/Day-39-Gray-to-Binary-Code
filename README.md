# Convert Gray Code to Binary Code
A program to convert a Gray code string back into its standard binary equivalent using string manipulation and the bitwise XOR operator.

## 📝 Description

This program reverses the conversion process introduced in Day 36. It takes a user-inputted **Gray code** sequence and translates it back into a standard base-2 **binary number**.

The mathematical algorithm for converting Gray to Binary is slightly different from Binary to Gray:

1. The Most Significant Bit (MSB - the first digit on the left) of the binary number is exactly the same as the MSB of the Gray code.
2. Every subsequent binary bit is generated by performing an **Exclusive OR (XOR)** operation between the *previously calculated binary bit* and the *current Gray code bit* (`binary_code[i - 1] ^ gray_str[i]`).

Similar to previous implementations, this script includes robust input validation. It utilizes Python's `all()` generator function to ensure the user string consists exclusively of '0' and '1' characters before attempting any calculations, preventing runtime errors.

---

## 🎯 Problem Statement

### Input:

* **Input 1:** A string representing a Gray code sequence (e.g., "1111").

### Output:

* If valid: Two formatted strings showing the original Gray code and its calculated binary equivalent.
* If invalid: An error message stating "Invalid input. Please enter a valid Gray Code consisting only of 0's and 1's."

### Rules:

1. The program must accept string input from the user.
2. The program must validate the input to ensure it contains only '0' and '1' characters.
3. If invalid, the program must reject the input gracefully.
4. If valid, the program must pass the string to the conversion function (`gray_to_binary`).
5. Inside the function, initialize the binary code string with the first character of the Gray code input.
6. Use a `for` loop to iterate from index 1 to the end of the string.
7. During each iteration, apply the bitwise XOR operator (`^`) between the *last character added to the binary string* and the *current character of the Gray code string*.
8. Convert the result to a string and append it to the growing binary sequence.

## 💡 Examples

### Example 1 (Standard Conversion)

**Input:**

```
1111


```

**Output:**

```
Gray Code: 1111
Corresponding Binary Code: 1010


```

**Explanation:** * 1st bit (MSB): Copied directly -> `1` (Binary)

* 2nd bit: 1 (Last Binary) XOR 1 (Current Gray) = `0`
* 3rd bit: 0 (Last Binary) XOR 1 (Current Gray) = `1`
* 4th bit: 1 (Last Binary) XOR 1 (Current Gray) = `0`
* The final string is `1010`.

### Example 2 (Consecutive Bits)

**Input:**

```
1010


```

**Output:**

```
Gray Code: 1010
Corresponding Binary Code: 1100


```

**Explanation:**

* MSB -> `1` (Binary)
* 1 (Binary) XOR 0 (Gray) = `1`
* 1 (Binary) XOR 1 (Gray) = `0`
* 0 (Binary) XOR 0 (Gray) = `0`
* The final string is `1100`.

### Example 3 (Single Bit)

**Input:**

```
1


```

**Output:**

```
Gray Code: 1
Corresponding Binary Code: 1


```

**Explanation:** The MSB is copied directly. Because the string length is 1, the `range(1, 1)` loop never executes, and it correctly returns `1`.

### Example 4 (Invalid Input)

**Input:**

```
1050


```

**Output:**

```
Invalid input. Please enter a valid Gray Code consisting only of 0's and 1's.


```

**Explanation:** The validation loop catches the non-binary character `5`, skips the calculation, and safely prints the error message.
